# ChatGPT Introduction

This repository contains solutions for the Holberton School ChatGPT Introduction project.

## Project Overview

The purpose of this project is to use ChatGPT as a tool to:

- Identify and fix bugs in existing code.
- Improve code quality and reliability.
- Add documentation to Python programs.
- Implement error handling mechanisms.
- Practice debugging in Python, HTML, and JavaScript.

## Tasks

### 0. Debugging - Python Factorial
Fixed an infinite loop in a factorial calculator.

### 1. Debugging - Python Arguments
Modified the script to print only command-line arguments without the script name.

### 2. Debugging - HTML / JavaScript
Fixed the button event handling to correctly change the page background color.

### 3. Debugging - Python Mines
Implemented a win condition for the Minesweeper game.

### 4. Documentation - Python Factorial
Added documentation to a recursive factorial program.

### 5. Error Handling - Python Checkbook
Added input validation and exception handling.

### 6. Debugging - Tic Tac Toe
Fixed gameplay issues and winner detection.
